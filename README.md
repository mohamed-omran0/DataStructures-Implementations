# DataStructuresImplementations

Collection of common data structures implemented in C++ with multiple variations.  
This repository is designed for learning, practicing, and showcasing data structures skills.

## Contents

- `vector/` – Dynamic array implementation.
- `stack/` – Stack implementations:
  - Using **array**
  - Using **linked list**
- `queue/` – Queue implementations:
  - Using **array**
  - Using **linked list**
- `linked_list/` – Singly linked list.
- `doubly_linked_list/` – Doubly linked list.
- `tree/` – Tree implementations:
  - **Binary Tree**
  - **Binary Search Tree (BST)**
  - **Heap (Min)**
- `hash_table/` – Hash table implementations:
  - **Open Addressing**
  - **Chaining**
- `dynamic_cast_example/` – Example demonstrating C++ **dynamic casting**.

## Features

- Implemented in **C++**.  
- Multiple variations for stacks, queues, and hash tables.  
- Clean code.  
- Good for portfolio, practice, and learning advanced C++ concepts like dynamic casting.
